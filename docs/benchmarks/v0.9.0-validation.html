Assembled release audit

  • release/v0.9.0 was created from master and contains only selected production, regression-test, ADR, final-report, and release commits. It contains no benchmark driver, machine-result JSON, prepared structure, or intermediate report.
  • All repository hooks passed, including formatting, Ruff, rumdl, and Clippy. The locked suite passed 82 Rust library tests, 7 CLI tests, 9 doctests, 15 Python tests, and ty.
  • The locked release build, wheel, source distribution, Cargo package listing, isolated wheel installation, and installed-wheel calculation passed. No HTML report is present in any package.
  • RustSec found no applicable vulnerability after updating h2 to 0.4.16. The recorded unmaintained warnings are bincode through Polars and paste through rust-sasa; two ignored quick-xml advisories are confined to uncompiled optional Polars metadata. The exact Python runtime packages, Polars 1.38.1 and polars-runtime-32 1.38.1, have no known vulnerability.
  • The release replay verified all 85 prepared-file hashes and reproduced the SASA/SAP figures in this report. The 6BFT H/L CLI repeated SC 0.7254 in 0.28 s at 34,632 KB peak RSS; these runtime measurements are local observations, not portable limits.

Method and provenance

  • Corpus: 85 retained PDBs from the RustSASA FreeSASA-reference set after one Rosetta preparation pass; identical prepared-file hashes were used for both versions.
  • Reference: installed Rosetta revision 597b55d6600c3939574ffee30a4469b26c3337bd, legacy TotalSasa/SasaFilter values from the existing benchmark artifact.
  • Arpeggia settings: public atom-level SASA path, hydrogens removed, 1.4 Å probe, 100 Shrake–Rupley points, one thread.
  • SASA versions: main 4135403 versus the assembled v0.9.0 production surface definition. The final N-terminal proline polarity correction is included in the reported partition metrics.
  • Because main did not expose polar/hydrophobic columns, its per-atom areas were partitioned afterward with the exact same Rosetta SasaFilter heavy-atom classifier used by HEAD. Thus the comparison isolates the change in surface radii/calculation path.
  • SAP reference: the same 85 Rosetta-prepared structures, installed Rosetta revision 597b55d6600c3939574ffee30a4469b26c3337bd, and 55,138 matched residue rows.
  • SC reference: pinned sc-rs core with identical 6BFT H/L atom input; the stock CLI value is shown only to document its preprocessing difference.
  • Runtime measurements are local observations, not portable hard limits.
